# Manual QA Portfolio: SauceDemo E-Commerce Testing

This repository contains end-to-end manual quality assurance documentation for the SauceDemo web application following the Software Testing Life Cycle (STLC).

## Project Documentation
- **01-test-plan/**: Overall test strategy, scope, environment configurations, and entry/exit criteria.
- **02-test-cases/**: Test suites covering functional requirements, positive paths, negative paths, and edge cases.
- **03-bug-reports/**: Detailed defect reports with severity ratings, steps to reproduce, and visual evidence.
- **04-rtm/**: Requirements Traceability Matrix verifying 100% test coverage.
- **05-test-summary/**: Final test execution summary, metrics, and deployment sign-off recommendations.
